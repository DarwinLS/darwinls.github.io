Production Platform / Applied AI

Veraflux

A production platform that pulls live clinical research from PubMed and turns it into evidence-based, fully-cited supplement reports personalized to age, sex, and goal. A roughly ten-stage LLM pipeline across two model vendors produces grounded synthesis where every claim links to a study you can open, rendered through a sophisticated React reading experience. Designed, built, shipped, and operated solo, front end to infrastructure.

  • React / TypeScript
  • Node / Express
  • Python / FastAPI
  • PostgreSQL
  • LLM orchestration (Gemini + Claude)
  • Docker / Railway
